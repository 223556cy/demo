# 需求 SPEC v1.2 — Issue #22 程序员模式 (Δ 增量)

---

## 系统背景

### 目的

OpenCalc (HarmonyOS 移植版) 当前仅提供基础与科学两个模式，无法满足开发者/学生/硬件工程师在调试、位运算、协议解析等场景下对二进制/八进制/十六进制的需求。本次新增**程序员模式**，允许用户在原 DEC 计算结果之外实时查看 BIN/OCT/HEX 三种进制的表示，并可在进制之间快速切换作为输入接续编辑，配套模式切换的平滑动画，使产品对标 iOS/Android 主流程序员计算器（如 macOS Calculator 程序员视图、Calc.exe）。

### 术语与缩写

| 术语/缩写 | 定义 |
| ----- | --- |
| Programmer Mode | 程序员模式，UI 视图状态之一 |
| BIN | Binary，二进制（基数 2） |
| OCT | Octal，八进制（基数 8） |
| DEC | Decimal，十进制（基数 10） |
| HEX | Hexadecimal，十六进制（基数 16），字符集 0-9 + A-F |
| activeBase | 程序员模式下当前正在编辑的基数（默认 DEC） |
| Number.MAX_SAFE_INTEGER | JavaScript 双精度浮点安全整数上限 2^53-1 |

### 关键体验路径（KEP）

- **KEP-01：进制实时查看**
  - 用户目标：键入 `255`，立即看到 DEC=255 / BIN=11111111 / OCT=377 / HEX=FF
  - 路径：进入程序员模式 → 按 2/5/5 → 4 行同步刷新
  - 体验预期：4 行内容同时显示，最长行（BIN）不换行，字号 14

- **KEP-02：跨进制接续编辑**
  - 用户目标：把 HEX 行的 'FF' 作为新算式 `FF+1`（activeBase=HEX），得到 HEX=100
  - 路径：点 HEX 行 → activeBase=HEX → expression=`FF`，可继续按 +1 →
  - 体验预期：点 HEX 行后，activeBase 高亮，键盘上 A-F 键变为可用

- **KEP-03：模式切换**
  - 用户目标：从标准模式切到程序员模式
  - 路径：点"模式"按钮 → ActionSheet 选"程序员" → 主面板 220ms 动画淡入
  - 体验预期：动画平滑无卡顿，模式后 4 行立即刷新

- **KEP-04：偏好持久化**
  - 用户目标：上次选程序员，下次启动直接是程序员
  - 路径：选程序员模式 → 杀进程 → 重启 App
  - 体验预期：aboutToAppear 读偏好后直接渲染程序员面板，无中间闪烁

#### 用例 UC-001-01：切换到程序员

##### 简要说明
用户在标准模式点"模式"按钮 → ActionSheet 选"程序员模式" → 主面板做透明度+位移过渡动画 → 持久化偏好。

##### Actor

| 角色 | 类型 | 与系统的关系 |
| --- | ------------ | ------ |
| 用户 | 主，人 | 直接触摸交互 |

##### 前置条件
- App 启动完成
- 模式 = STANDARD
- expression 任意状态（保留，不清空）

##### 最小保证
ActionSheet 必须能弹出并响应点击。

##### 成功保证（后置条件）
- mode 状态置为 PROGRAMMER
- 偏好持久化为 true
- 4 行进制显示区可见
- 当前 expression 的 DEC 值在 4 行中显示

##### 触发事件
用户点击 ToggleRow 头部"模式"按钮。

##### 主成功路径（基本事件流）
```
1. 用户在标准模式点 ToggleRow 头部"模式"按钮
2. 系统弹出 ActionSheet（含"标准模式"/"程序员模式"两项）
3. 用户点"程序员模式"
4. ActionSheet 关闭
5. animateTo 启动（duration=220, curve=EaseInOut）
6. 标准面板透明度 1→0、translateY 0→8
7. 程序员面板透明度 0→1、translateY 8→0
8. mode = 'programmer'，触发 UI 重渲染
9. 4 行进制显示当前 expression 的 DEC 值
10. setProgrammerModeDefault(true) 异步落盘
```

##### 扩展路径
```
1a. 用户在 ActionSheet 上点屏幕外部
    → ActionSheet 关闭，状态不变
1b. 模式按钮不可见（如横屏时）
    → 兜底：横屏保持 ToggleRow 显示，不允许折叠
2a. 偏好写入失败（如磁盘满）
    → 静默失败，不影响当前会话；启动下次仍用上上次值
```
