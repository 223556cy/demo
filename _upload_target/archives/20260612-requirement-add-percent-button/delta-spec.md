## 系统背景

### 目的

OpenCalc 是一款 HarmonyOS ArkTS 科学计算器应用。本次新增百分号（`%`）按钮，旨在解决日常高频计算场景（如折扣、税率、百分比增减）中用户需要手动展开百分比的痛点。核心价值：用户输入 `50+10%` 即可一键得出 `55`，减少心智负担，提升 UX，立竿见影。

### 术语与缩写

| 术语/缩写 | 定义 |
| --- | --- |
| `%` 操作符 | 数学百分号，含义为"乘以 0.01"，但在计算器上下文中具有重写语义 |
| Windows 风格语义 | `a+b%` 展开为 `a+a*b/100`，区别于传统数学语义 `a+b/100` |
| KEP | Key Experience Path，关键体验路径 |
| KEI | Key Experience Indicator，关键体验指标 |
| 解析链 | 用户输入 → 表达式字符串 → 解析后的运算表达式 → 引擎求值 |
| 重写语义 | 在 `getCleanExpression` 阶段将 `%` 字符替换为等价数学表达式的过程 |

### 关键体验路径（KEP）

- **KEP-J01-01 折扣计算**：
  - 用户目标：一键计算折扣价（如"原价 200，打 8.5 折，输入 200-15%"）
  - 路径：用户点击 `2`-`0`-`0`-`-`-`1`-`5`-`%` → 自动展开为 `(200)-(200)*(15/100)` → 按 `=` → 显示 `170`
  - 体验预期：用户无需理解内部展开规则，仅需输入"200-15%"即可得到 170；过程零错误

- **KEP-J02-01 百分比增加**：
  - 用户目标：计算"50 增加 10%"后的值
  - 路径：用户点击 `5`-`0`-`+`-`1`-`0`-`%` → 自动展开为 `(50)+(50)*(10/100)` → 按 `=` → 显示 `55`
  - 体验预期：与示例需求完全一致；显示"55"作为最终结果

- **KEP-J03-01 错误恢复**：
  - 用户目标：在 Error 状态（如除零）下，按 % 按钮能继续输入
  - 路径：触发除零 Error → 用户按 `%` → 状态从 Error 转为"%"注入到空表达式
  - 体验预期：用户感觉"按下按钮有反应"，不被困在 Error 状态

#### 用例 UC-001-01：加法场景 % 语义

##### 简要说明

当表达式形如 `a+b%` 时，解析器将 `%` 替换为 `a*b/100`，并将整个表达式转换为 `(a)+(a)*(b/100)` 后求值。

##### Actor

| 角色 | 类型 | 与系统的关系 |
| --- | --- | --- |
| 用户 | 主，人 | 触发输入和计算 |
| 解析器 | 次，系统 | 接收表达式字符串，输出重写后的表达式 |

##### 前置条件

| 场景要素 | 本用例采用的取值 | 对用例的影响点 | 处理方式 |
| --- | --- | --- | --- |
| T | 运行期 | 必须在运行期，不能离线/启动期 | 保持 |
| G | 计算加法 % | 仅限加法 | 保持（其他运算拆分用例） |
| E | 键盘输入 | 表达式来自 UI | 保持 |
| A | 用户 | 触发输入 | 保持 |
| S | 正常 | 表达式有效，b 不为负 | 扩展（见 UC-001-04） |

##### 最小保证

表达式至少能被识别为非法（不崩溃），或被正确解析为 `(a)+(a)*(b/100)`。

##### 成功保证（后置条件）

- 表达式被重写为 `(a)+(a)*(b/100)`
- 求值结果 = `a + a*b/100`（在 `getCleanExpression` 阶段）
- UI 显示结果（按 = 后）

##### 触发事件

用户在键盘上点击 `%` 按钮，触发 `onPercentClick` 事件，传入当前表达式字符串。

##### 主成功路径（基本事件流）

```
1. 用户输入 `50`
2. 用户点击 `+`，表达式变为 `50+`
3. 用户输入 `10`
4. 用户点击 `%`
5. 解析器识别到 `a+b%` 模式（a=50, b=10）
6. 解析器重写为 `(50)+(50)*(10/100)`
7. 表达式显示为 `50+10%`（用户视角保持不变）
8. 用户点击 `=`
9. 计算引擎求值 `(50)+(50)*(10/100)` = 55
10. UI 显示 55
```

##### 扩展路径

```
1a. 用户点击 `%` 时表达式为空：进入 UC-001-03（一元 % 错误）
2a. 表达式以 `+` 结尾（`50+`）：报错"请先输入数字"
3a. 表达式以 `+0` 结尾（`50+0%`）：重写为 `(50)+(50)*(0/100)` = 50，不报错
4a. 表达式有多个 %（`50+10%*2%`）：见 SC-007 重复 % 错误处理
```
