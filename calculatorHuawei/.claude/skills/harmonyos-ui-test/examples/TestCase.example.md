# AI PPT 生成器 测试用例

> 应用: com.example.aippt | 默认账户: VIP | 测试设备: 模拟器

## 首页

- [ ] **(VIP) 点击"立即生成"按钮** → 预期: 跳转到大纲生成页面
- [ ] **点击"设置"图标** → 预期: 弹出设置菜单，显示"关于"、"退出"选项
- [ ] **(非会员) 验证水印显示** → 预期: 页面底部显示"Powered by AI"水印
- [ ] **验证首页标题** → 预期: 显示"AI PPT 生成器"标题文字

## 大纲生成页

- [ ] **输入主题"AI的未来发展趋势"** → 预期: 输入框显示完整文本，字数统计显示12字
- [ ] **点击"立即生成"按钮（大纲）** → 预期: 按钮变为不可点击状态，开始生成
- [ ] **[生成中] 验证loading动画显示** → 预期: 显示旋转loading图标和"正在生成大纲..."文案
- [ ] **[生成中] 验证"停止生成"按钮可用** → 预期: 显示可点击的"停止生成"按钮
- [ ] **[生成完成] 验证大纲内容正确** → 预期: 显示3个以上章节标题，每个章节有至少1个子标题
- [ ] **[生成完成] 验证"重新生成"按钮显示** → 预期: 显示"重新生成"按钮
- [ ] **[生成完成] 验证"选择模板"按钮可用** → 预期: "选择模板"按钮高亮可点击
- [ ] **点击大纲中的第一个章节标题** → 预期: 该章节高亮选中，显示选中状态

## 模板选择页

- [ ] **验证模板列表显示** → 预期: 显示6种以上模板，每种有缩略图和名称
- [ ] **(VIP) 点击VIP专属模板"科技蓝"** → 预期: 进入模板预览页面
- [ ] **(非会员) 点击VIP模板"科技蓝"** → 预期: 弹出"开通会员即可使用"提示弹窗
- [ ] **(非会员) 点击免费模板"简约白"** → 预期: 进入模板预览页面
- [ ] **点击"返回"按钮** → 预期: 回到大纲生成页面，大纲内容保持

## PPT生成页

- [ ] **验证"生成PPT"按钮显示** → 预期: 显示"生成PPT"按钮，标注预计耗时
- [ ] **点击"生成PPT"按钮** → 预期: 开始生成，显示进度百分比
- [ ] **[生成中] 验证进度百分比更新** → 预期: 进度数字持续增长
- [ ] **[生成完成] 验证"下载PPT"按钮显示** → 预期: 显示"下载PPT"和"在线预览"两个按钮
- [ ] **(非会员) 验证免费次数限制提示** → 预期: 显示"今日剩余X次免费生成"

## 设置页

- [ ] **点击"关于"选项** → 预期: 显示应用版本号和版权信息
- [ ] **点击"退出登录"** → 预期: 弹出确认对话框"确定要退出登录吗？"
- [ ] **在退出确认中点击"确定"** → 预期: 退出到登录页面
