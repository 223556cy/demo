**200 个采样点的 y 值全部满足 `y ≈ x * π/180`** —— 这是 `sin(x°)` 在小角度的线性近似 (sin(x°) ≈ x*π/180)。

### 根因 (rev-01 定位)

`opencalc/entry/src/main/ets/pages/GraphPage.ets` 第 46-62 行的 `aboutToAppear()`:

```typescript
aboutToAppear(): void {
    // ...
    this.prefs.init().then((): void => { this.loadPrefs() })   // 微任务
    setTimeout((): void => { this.vm.compute() }, 0)          // 宏任务
}
```

ArkTS 事件循环规则:**微任务先于宏任务** 执行。所以:
1. `prefs.init().then(loadPrefs)` 是微任务,先跑 → `loadPrefs()` 调 `getRadiansDefault()` 返回 `false` (用户默认角度) → `vm.setRadianMode(!false)` = `setRadianMode(true)` → **`vm.isDegree = true`**
2. 然后 `setTimeout` 宏任务跑 → `vm.compute()` 闭包捕获 `this.isDegree=true`
3. 200 个采样点都按角度模式算 sin → 几乎全在小角度 → 直线

### dev-01 你要做

**修复方案 (rev-01 推荐)**：把 `vm.compute()` 移到 `loadPrefs` 的 `.then()` 里,确保首次计算前 isDegree 已被正确设置:

```typescript
aboutToAppear(): void {
    // ...路由参数解析...
    const ctx: common.UIAbilityContext = getContext(this) as common.UIAbilityContext
    this.prefs = new PreferencesStore(ctx)
    this.prefs.init().then((): void => {
      this.loadPrefs()
      this.vm.compute()  // ← 在这里调,等 loadPrefs 完成
    })
    // 删除 setTimeout 那行
}
```
