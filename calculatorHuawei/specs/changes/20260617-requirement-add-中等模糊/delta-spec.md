## 系统背景

### 目的

在 Issue #18 已实现 4 大类单位换算（length/temperature/mass/volume）的基础上，扩展支持 area/time/speed 3 大类，覆盖工程/学习/出行的常见换算需求。系统为 OpenCalc 计算器用户解决"打开专门换算 App 太麻烦"的问题，让用户在计算器输入框直接通过自然语言完成面积/时间/速度换算。

### 术语与缩写

| 术语/缩写 | 定义 |
| ----- | --- |
| NL | Natural Language，自然语言 |
| 因子表 | 单位换算基准表，每个类别以一个"基准单位"为锚点，其他单位相对基准的倍数 |
| Alias / 别名 | 用户在 NL 输入中可能使用的单位名称（中文/英文/缩写/同义词） |
| 标况声速 | 海平面 15°C 条件下声速 340.29 m/s，作为 1 mach 的换算基准 |
| 月/近似 | 1 mo = 30 × 86400 s（工程近似，不区分实际月份天数） |
| 年/近似 | 1 yr = 365 × 86400 s（工程近似，不区分闰年/平年） |
| 亩 | 中国市制面积单位，1 亩 = 2000/3 m² ≈ 666.6667 m² |
| 节 (knot) | 航海速度单位，1 knot = 1852/3600 m/s ≈ 0.51444 m/s |

- **KEP-01（工程/学习换算）**：

##### 主成功路径（基本事件流）
```
1. 用户在输入框输入"100亩转平方米"
2. NaturalLanguageParser.parse 提取 (value=100, from="亩", to="平方米", category="area")
3. UnitConverter.convert(100, "mu", "m2", "area") 计算得 66666.6667
4. 预览区显示 "66666.67 m²"
```

##### 扩展路径
```
1a. 用户输入 "100 m² to acre"（英文+缩写+复合）
   → 解析器识别 m²（alias→"m2"），识别 acre（alias→"acre"）
   → 调用 UnitConverter.convert(100, "m2", "acre", "area") → 0.0247105
   → 预览 "0.0247105 acre"
```

## 因子表附录（实现参考）

### area（基准：m²）
```
m2    = 1.0
cm2   = 0.0001
km2   = 1_000_000.0
ft2   = 0.09290304
in2   = 0.00064516
yd2   = 0.83612736
acre  = 4046.8564224
hectare = 10000.0
mu    = 2000.0 / 3.0    // 中国"亩"，约 666.6667 m²
```

### time（基准：s）
```
ms   = 0.001
s    = 1.0
min  = 60.0
h    = 3600.0
d    = 86400.0
wk   = 604800.0        // 7 × 86400
mo   = 2592000.0       // 30 × 86400
yr   = 31536000.0      // 365 × 86400
```

### speed（基准：m/s）
```
m_s     = 1.0
kmh     = 1000.0 / 3600.0           // ≈ 0.277777...
mph     = 1609.344 / 3600.0         // ≈ 0.447040...
knot    = 1852.0 / 3600.0           // ≈ 0.514444...
mach    = 340.29                    // 海平面 15°C 标况声速
```
